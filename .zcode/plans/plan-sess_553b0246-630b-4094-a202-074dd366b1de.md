# 研究生三年发展路径·决策工作台（第一版）

## 实现边界
- 采用现有设计方向：**零依赖静态单页站点**，支持直接双击 `site/index.html`（`file://`）和本地 HTTP 两种打开方式。
- 不引入 React/Vue、npm、构建流程或运行时 `fetch`；继续使用经典脚本按顺序加载全局数据。
- **不做毕业倒计时，不做持久化**。勾选、筛选和验证状态仅在当前页面会话生效；数据结构保留稳定 ID，便于后续接入持久化。
- 不把 `.jobs/baidu.json` 的 1,287 条原始记录复制进站点；只使用可复算的聚合统计、代表岗位与明确的数据边界。

## 一、补齐并整理数据层

### 1. 新增 `site/data/jobs.js`
包含：
- 百度招聘快照元数据与口径：1,287 条关键词检索去重记录，而非“百度全部 AI 岗位”。
- 招聘类型、岗位类型、城市分布（明确多城市重复计数、记录数不等于 HC）。
- 九类岗位族及个人匹配策略。
- 8–12 个高信息密度代表团队/岗位。
- 实习四级阶梯、2026–2029 求职时间线与阶段验收标准。
- 重庆、成都、杭州等地域策略。
- 数据风险与生涯风险。
- 每条关键记录带 `id`、`claimType`、`evidenceLevel`、`sourceAsOf`、`freshness`，严格区分事实、推断、待核验和预测。

### 2. 新增 `site/data/skills.js`
包含：
- 百度 747 个技术岗与腾讯 419 个技术岗的**分开统计口径**，不合并百分比。
- Python、Go、分布式、评测、可观测性、Memory、Context、MCP、RAG、K8s 等市场信号矩阵。
- P0–P3 学习优先级、目标水平、截止阶段和可验证交付物。
- 算法题、计算机基础、Agent 工程、系统设计四条面试能力线。
- 明确“文本命中率不等于岗位硬要求率”“GraphRAG 零命中不等于技术无价值”。

### 3. 新增 `site/data/portfolio.js`
包含：
- AgentParliament v2：Trace、Eval、图记忆三阶段。
- 代码知识图谱 + Agent 根因分析项目。
- 每个项目的架构、权衡、里程碑、关联岗位、证据产物和验收条件。
- QPS、成功率、P99、单位成本默认保持 `null`/“待实测”，绝不把目标值冒充成果。
- 求职叙事、简历表达、面试故事和“错误选择→测量→纠正”模板。

### 4. 完善 `site/data/tools.js`
保留已有科研工具链主体，并补足缺失规范：
- 文献发现：Scholar、Semantic Scholar、DBLP、arXiv、Crossref、OpenAlex、ResearchRabbit/Litmaps、Papers with Code、GitHub；加入前向/后向引文追踪和提醒策略。
- 文献管理：Zotero + Better BibTeX，统一收藏夹、标签、命名、去重、DOI/arXiv 元数据核验规范。
- 阅读记录：三遍法 + 固定的 Problem/Assumption/Method/Data/Baseline/Metric/Result/Limitation/Reproduction/Thesis relevance 模板。
- 论证管理：claim–evidence matrix、related-work taxonomy、不可用 AI 摘要替代原文核验。
- 实验工程：Git、uv/Conda、Docker、PyTorch/PyG、YAML/Hydra、MLflow/W&B、pytest、Ruff、必要时 mypy/DVC；记录 seed、commit、config、硬件、模型/API 版本、prompt、token、费用和原始输出。
- 可复现规范：至少 3 次运行与 mean±std、消融、强 baseline、错误分析、数据泄漏检查、负结果保留。
- 写作与伦理：LaTeX/BibTeX、引用核验、矢量图、AI 使用披露、COPE/目标期刊政策、保密和第三方服务数据边界。
- 增加可交互的“实验可复现检查表”和“投稿前检查表”。
- 修正文案中可能过时或过度确定的工具/政策描述，统一标“投稿前以目标期刊原文为准”。

### 5. 保留并兼容现有数据
- 复用 `facts.js`、`research.js` 的丰富内容，不大规模重构已有 schema，避免引入无必要风险。
- 仅修正会造成明显误读的表达，例如实习三个月推断必须突出“未核实”，不能写成可依赖规则。
- 渲染层对缺字段、`null`、二维数组和混合字段做兼容，页面不显示 `undefined`。

## 二、创建入口和渲染层

### 1. 新增 `site/index.html`
- 语义化页面骨架、固定侧栏、移动端遮罩、粘性顶栏、搜索、主题按钮、主内容容器和页脚。
- 按固定顺序加载 facts/research/tools/jobs/skills/portfolio/app。
- 页脚固定说明：数据截至 2026-07-28；未来招聘批次为历史规律外推，应以官方公告为准。

### 2. 新增 `site/assets/app.js`
使用原生 JavaScript 建立小型渲染器和统一组件：
- 页面头、统计卡、证据徽章、来源说明、表格、时间线、折叠面板、研究切口卡、论文条目、岗位卡、技能矩阵、任务清单。
- 路由使用 URL hash，支持前进/后退、直接定位、当前导航高亮。
- 受控富文本只用于仓库内静态策展数据；岗位/JD 和搜索文本使用 `textContent`，避免以后把外部数据直接注入 HTML。

## 三、页面信息架构

1. **总览仪表盘**：个人定位、三条关键纠偏、总策略、近期行动、关键风险；无倒计时。
2. **现实基线**：导师画像、论文方法签名、学校制度、校企资源、就业事实、信息盲区。
3. **研究主线**：双重话术、五个切口评分对比、首篇方案、饱和方向、竞争团队、双轨实验与指标。
4. **阅读与 90 天启动**：分层论文清单、筛选、仓库/数据集、12 周路线、里程碑和回退策略。
5. **科研工具链与规范**：发现→管理→阅读→实验→写作→投稿→伦理的闭环，以及检查表。
6. **实习与岗位**：招聘统计、岗位族、代表团队、地域策略、实习阶梯与招聘时间线。
7. **技能矩阵**：市场信号双口径、P0–P3、目标水平、交付物和面试能力线。
8. **作品集**：两个核心项目、阶段里程碑、四项核心指标空位、岗位映射与工程叙事。
9. **求职资产**：论文到 JD 的语言翻译、简历标签、离职/读研叙事、面试开场、投递优先级。
10. **待核验清单**：学位成果要求、实习完整政策、算力、OSPP、重庆岗位、未来招聘窗口等，按影响和证据状态筛选。

## 四、交互与视觉
- 全站搜索：在当前策展内容中检索并显示匹配页面/板块，支持点击跳转；不伪装成原始 1,287 条岗位搜索。
- 岗位筛选：招聘类型、生涯阶段、城市、岗位族、目标层级、证据等级。
- 论文筛选：阅读层级、是否必读/撞方向、图学习类别。
- 技能筛选：优先级与能力域。
- 切口对比：五维评分可视化，突出 A 为首选但保留风险说明。
- 清单与进度：阅读、90 天、科研规范、作品集、验证项均可临时勾选并实时计算进度；刷新后重置，明确标注“当前会话”。
- 深浅主题仅作会话状态，不写入存储。
- 移动端侧栏支持按钮、遮罩、Escape 关闭；导航后自动收起。
- 所有按钮/导航使用语义化元素，支持键盘和明显焦点状态；证据等级除颜色外显示文字。

## 六、验证与自审
1. 对全部数据脚本和 `app.js` 执行 `node --check`。
2. 运行数据断言：百度记录数与分类复算、稳定 ID 唯一、枚举合法、论文内部引用无明显悬空、页面路由均有渲染函数。
3. 同时验证 `file://` 与本地 HTTP 打开方式，检查控制台无错误和无 `undefined/null` 泄漏。
4. 测试导航、hash 前进后退、搜索、岗位/论文/技能筛选、临时清单进度、主题、移动侧栏和 Escape。
5. 检查 360、768、1024、1440px 响应式表现和键盘可操作性。
6. 完成后对 diff 做独立代码审查与测试覆盖审计；修复高/中严重度问题后再交付。
